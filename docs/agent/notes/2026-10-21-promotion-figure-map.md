## Proposed text for the promoted report (figures section)

> Figures. Four figures are written with the report; each is drawn from the stored results of the run labeled `CONFIRMATORY: UNPROMOTED` and each shows point values only, with no confidence interval. (1) `separation_weight_vs_horizon.png`: experiment E4; informs H2a; median and inter-quartile range of w* against the horizon (the band is a spread across states, not a confidence interval). (2) `kaplan_meier_by_rule.png`: experiment E4; the rules whose differences H2c, H2d and H3c test; survival curves, no verdict. (3) `regret_vs_regimes.png`: experiment E5; informs H3c; abstraction regret against the number of regimes K. (4) `knob_response_library.png`: experiments E1 and E2; informs H2b; median w* against library size, one curve per noise level. The intervals behind the verdicts are in the verdict table and in the interval labels of the report, not in these figures (moving-block bootstrap, blocks of 5, B = 2000; level 1 - 0.05/3 for H2a, H2b, H3c and 95% otherwise).
