### B4. Which device runs the confirmatory run and its regeneration, and how the Chua V6 failure of R5 is read (plan amendment 1, A12 O4; O3; DEF-0026)

**What.** GPU and CPU build different trajectories (context digests differ completely; tier TD), so for the same seed they are different realizations. DEV-2 full: GPU context fails the gate (Chua V6 2.405e-3 against 1e-3; R5), CPU context passes (V6 3.3e-4; R6). R5 against R6 passes the TD statistic (max |z| 2.26 away-arm) while 52 verdict-type leaves differ. GPU repeats on this host are bitwise (R1 = R2); CPU repeats are bitwise at the same `LPC_THREADS` (DEF-0023: the thread count changes results in the last bits, so it belongs in the freeze configuration). Wall time: GPU full 2739 s (0.76 h); CPU full 17031 s (4.73 h, other lanes may have shared the CPU). V6 fails per fresh seed with probability about 4.6% on Chua and 4.8% for any system; V4 or V6 combined 11-25% per seed at full size (DEF-0026); a sealed-run gate failure is a hard stop, referred to the owner and never retuned (DEC-0027). The owner declined a pre-seal response rule (§26). The draft decision for WU-0003.6 states explicitly that the device is "not decided here" (§34 point 5).
Also decide: whether the passing runs R1/R3/R6 satisfy "validation gate V1-V7 passes on all three systems in the rehearsal" (LPC.PC.6) with R5 recorded under DEF-0026, or whether the rehearsal must pass at full size on the chosen device. And O3: whether GPU runs set `XLA_FLAGS=--xla_gpu_deterministic_ops=true` (moot if the CPU is chosen; unneeded so far, since R1 = R2 bitwise without it).

**Why it blocks.** The freeze records "the configuration" (LPC.PC.8); the regeneration tolerance (tier T0 versus TD) and WU-0015/WU-0016 depend on it; on the GPU the only full-size rehearsal (R5) failed the gate that the freeze requires to pass.

**Options.**
1. Sealed run and regeneration on the CPU at a fixed `LPC_THREADS` (8 in all rehearsal runs). Consequence: regeneration can be bitwise (T0); 4.7 h wall, under the 12 h limit; rehearsal evidence at both sizes passes (R3, R6); nothing about the sealed seed's V6 changes (the 4.6% remains).
2. Both on the GPU (same device type). Consequence: fast; bitwise on the same host/GPU, but a regeneration by another actor on another GPU is a TD pair, not bitwise; the only full-size rehearsal on this device failed V6.
