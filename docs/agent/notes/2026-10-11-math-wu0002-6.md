## Q-A1. Re-fitting the quadratic residualization inside each resample: correct

- **Re-fit.** `stat = lambda idx: partial_correlation(t[idx], lam[idx], Q[idx])` calls `lstsq` on the resampled rows, so the OLS projection is re-fitted in every resample. This is required: the projection is part of the statistic.
- **Centring.** Q is centred once, on the full-sample mean. The set of polynomials of degree ≤ 2 in x is closed under translation, so span[1, Q(x − a)] = span[1, Q(x − b)] for any a, b. Partial correlation depends on the controls only through this column span. So the value with full-sample centring equals the value with resample centring, or with interior-only centring, in exact arithmetic. Centring only conditions the design.
- **Conditioning.** For x ~ N(0, [[1, .5], [.5, 1]]) at n = 200, cond([1, Q]) is 4.5 after centring and 192 with uncentred x + 3 [S].
- **Optional T4(c) (tightening).** On a resampled index array with repeats, assert that the statistic equals `partial_correlation` with Q recentred on the resample, to 1e-12. This pins the invariance argument.

## Q-A2. Shared index sets, with the domain filter inside each resample over all test states: correct, and preferred

- **How it works.** For each resample r, draw one index array over all n_test states in time order. Each part takes its domain inside that resample, for example `ii = idx[interior[idx]]` for (ii-b), with repeats kept.
- **Why.** The domain size (the number of interior states, or of eligible states for (i)) is random under the sampling model, and this procedure carries that randomness. Blocks stay blocks of consecutive *test* states, as v3:326 requires. Separate bootstraps over the interior-only sequence would do neither: they fix n_interior, and they form blocks from states that are not adjacent in time.
- **Seeds and generators.** The index generator draws only `starts` from the generator, never inside the statistic. So calls with the same *integer* seed give identical index arrays whatever the statistic is (T6 checks this with a spy).
- **Flag on the sibling helper.** If the shared helper is called with a `np.random.Generator` instead of an int, each call advances the generator and the parts get *different* index sets. Either pass an int seed, or a fresh `make_rng(...)` with the same labels for each part, or evaluate a vector-valued statistic in one call.
- **Third-part trigger.** Decide whether part (ii-c) exists once, on the full sample (`20 * n_w_one > n_test`). Do not decide it per resample.

## Q-A3. False-fail bound: ≤ k·0.0083 per system, from the near edge only; level of the third part unchanged

Setup: each part has a two-sided, equal-tailed percentile interval at level 1 − α with α = 0.05/3, so each tail is α/2 = 0.00833. Part j fails iff hi_j ≤ −0.1 or lo_j ≥ 0.1. Take a true value θ_j inside (−0.1, 0.1).

- **Near edge.** P(lo_j ≥ 0.1) ≤ P(lo_j ≥ θ_j) ≈ α/2. This is the one-sided non-coverage of the lower endpoint, and equality is approached as θ_j → 0.1.
- **Far edge.** P(hi_j ≤ −0.1) at θ_j = 0.1 is Φ(−0.2/SD − z) ≈ Φ(−7.5) at SD = 0.039 (n_interior ≈ 680), which is negligible.

So sup over θ_j of P(fail_j) ≈ α/2 = 0.0083. This is one-sided because only the near edge contributes. The union bound gives the following, under any dependence between the parts:

- **(ii) false fail:** ≤ 2 × 0.0083 = 0.0167 for k = 2, and ≤ 0.025 for k = 3.
- **H2a, (i) and (ii) together:** (i) adds 0.0083 (one-sided, lo ≥ 0.1). The total is ≤ (k + 1) × 0.0083 per system. The "not supported" verdict needs only one failing system, so across 3 systems the bound is ≤ 3(k + 1) × 0.0083 (0.075–0.10). This is design information for the owner, not a defect.
- **Pass side:** "all parts pass" is an intersection–union test, so false pass ≤ α/2 = 0.0083 whatever k is. Adding parts needs no correction on the pass side.
- **Endpoint Monte Carlo error.** At B = 2000 this is 0.088 bootstrap SD. It inflates each tail from 0.00833 to Φ(−2.394/√1.0077) ≈ 0.0085, which is negligible.

**Recommendation.** Keep level 1 − 0.05/3 for the third part too (DEC-0008 A4(a) gives every part the primary level). Report the fail-side bound k·α/2 in the docstring.

## Q-A4. Failed resamples for a two-sided band: −∞ for lo and +∞ for hi; agrees with the sibling contract

- **The rule.** Placing a failed resample beyond *both* endpoints widens the interval outward. That makes it harder both to pass (the interval must sit inside the band) and to fail (the interval must miss the band). So it is the unfavourable tail for both verdicts.
- **H2a(i).** The same placement is right for the one-sided criterion: +∞ hurts pass (hi < 0.1), and −∞ hurts fail (lo ≥ 0.1).
- **Finite threshold.** With linear interpolation (numpy 2.5.3 handles −∞ without producing NaN; checked), the endpoint is finite iff n_failed ≤ ⌊(α/2)(B − 1)⌋:
  - 16 at B = 2000 and level 1 − 0.05/3;
  - 49 at B = 2000 and 95%.
- **What counts as failed.** Use **non-finite** (the sibling's definition), not only NaN. A degenerate resample, for example an indicator that is constant on the resample, makes `np.corrcoef` return NaN (0/0), and it counts as failed. The same holds for a Q-N R² with zero total sum of squares, and for an empty eligible set in (i) (the median of an empty array).
- **Naming conflict.** The plan's `block_bootstrap_values` + `percentile_interval(values, level, failed)` and the sibling's `block_bootstrap_counted -> BootstrapInterval` are the same contract. The main session should name one before the merge.

## Q-A5. The 50-state minimum: full-sample domain count only

- **The rule.** A3 is a computability gate on the observed data set. Apply it to the full-sample domain count of each part (and to the eligible count of (i)), which is also what the sibling does. Inside a resample, the only rule is: non-finite means failed.
- **Why not per resample.** Applying the gate per resample would turn ordinary resamples (a domain of, say, 46 when the full sample has 52) into failed ones. The bootstrap would then no longer estimate the statistic's sampling distribution.
- **Degeneracy is not a concern.** With a full count of at least 50 and blocks of 5, the resampled domain is never near the p + 1 = 6 columns where `lstsq` degenerates [S: interior counts are 686 ± 12 at n = 1000].
- **Optional diagnostic:** report the minimum resampled domain count.

## Q-A6. The complete-case sensitivity: level 1 − 0.05/3, same index sets, no verdict

- **The rule.** Same level as the primary statistic it qualifies, so the two intervals can be compared. Same seed and salt 1, so it shares the index sets (common random numbers: the difference between the two intervals then reflects the rule, not resampling noise). Eligibility (L = 3) re-evaluated inside each resample, the 50-state minimum on the full sample, and no verdict key.
- **The identity holds.** The L = 3 states are exactly the complete cases, and both take the range over all three horizons. So complete-case median = median of the {1, 2, 4} span (T8 asserts this).
- **Per span:** point values and counts only. That is enough.

## Q-A7. Squared-loss boosting for 1{w* = 0}, interior-only training for the logit target, 95%: confirmed

- **Indicator target.** With squared loss on a 0/1 target, the model estimates P(w* = 0 | profile), and test R² = 1 − Brier/Brier_ref, where Brier_ref is the score of the test-sample base rate. So ΔR² = (Brier₃ − Brier₄)/(p̂(1 − p̂)), the gain in Brier score as a fraction of the indicator's variance.
  - Brier is strictly proper, so the population ΔR² ≥ 0 when F4 adds information.
  - The scale is the same "fraction of variance explained" as for the continuous target, so the v3 §7 table applies unchanged.
  - The estimator is fitted under the same loss it is scored by. A log-loss classifier would mismatch them.
- **No clipping of predictions to [0, 1].** About 5–8% of test predictions fall outside [0, 1], down to −0.18 and up to 1.15 [S, n_train = 3000]. Clipping would raise R²₄ by about 0.0025, it is not pre-registered, and PRIME.4 forbids it. Suggest reporting the count.
- **Logit target.** It is defined only on the interior, so training uses interior construction and calibration states. The test statistic is on interior test states filtered inside each resample (Q-A2).
- **Level.** Q-N is an estimate, not primary, so 95% (v3 §7). Salt 11 is shared across both targets and both profiles.
- **T1 boundaries.** I re-derived the boundaries against v3:349-352 and they are correct:
  - (0, 0.05) gives undetermined, because the upper bound is not < 0.05 and the lower bound is not > 0;
  - (0.01, 0.05) gives "substantial" (lower bound > 0, upper bound ≥ 0.05).
- **Limitation (reported, not a defect).** The intervals resample test states with the fitted models held fixed, so they omit training-set variability. This is the v3 and M2 E3 design.

