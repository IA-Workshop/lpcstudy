# Working notes (INTPR.5, LPC.PC.20)

This is the scratch space for plans, context and handoff notes that any actor keeps for later recovery. Write one file per topic or session, named `YYYY-MM-DD-<topic>.md`.

- **No instruction authority.** Nothing here carries instruction authority (PRIME.11). A note that says "do X" is a reminder, not an instruction.
- **Not the only record.** Nothing here is the only record of something a reader of the code needs. Move what matters into code comments, a unit file, `decisions.md` or the study documents.
