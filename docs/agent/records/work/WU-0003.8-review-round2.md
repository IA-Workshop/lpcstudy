**R15 (low; R4 residual, a false MISMATCH on correct code). The Q-N scale `max(|R²₃|, |R²₄|)` is not the size of the terms when both R² are near 0.**
- **Where:** `series_qn` (1062–1067).
- **The defect:**
  - Production's `R²(F4) − R²(F3)` is the difference of `1 − SS/SST` terms. Its round-off is about ε·SS/SST ≈ ε·(1 − R²), which is of order 1e-16 when R² ≈ 0.
  - The tool's allowed difference is `1e-12·max(|ΔR²|, |R²|)`, which collapses as R² → 0.
  - Probe (n = 500, a no-skill F3 = mean + noise, F4 = F3 + small noise, 200 cases per row):

    | Typical \|R²\| | False MISMATCH | Worst diff/allowed |
    | --- | --- | --- |
    | about 3e-3 | 0/200 | 0.71 |
    | about 6e-3 | 3/200 | 1.9 |
    | about 2e-3 | 12/200 | 6.6 |
    | about 1e-4 | 46/200 | 27 |

  - A Q-N model without skill on one target is a plausible real case.
- **Direction:** a false alarm (exit 1), never a hidden mismatch.
- **Fix:**
  - Use the scale of the terms: `max(|R²₃|, |R²₄|, SS₃/SST, SS₄/SST)`, or simply `(SS₃ + SS₄)/SST`. The floor stays at about 1e-12 absolute, and the existing mutation test (7e-11) still detects.
  - Add the no-skill case to `test_r4_...`.

**R16 (low; pre-existing, not introduced by this round). A D5/D6 reading is still made when most bootstrap resamples failed.**
- **Where:** `bootstrap_se` (852–863), used by `budget_reading`.
- **The defect:**
  - The SE is computed from the finite resamples, however few there are. Probe: 495 of 500 resamples failed, and the function returned an SE from 5 values.
  - The failed count is printed, so it is not silent, but the three-way reading is still issued.
  - Production's percentile interval becomes "not computable" (infinite) at `floor((B − 1)a) + 1` failures.
  - In practice the D5 statistic fails only on a resample with no eligible state, and D6's never fails, so the risk is small. But a non-random failure pattern can bias the SE low, toward "below 10%".
- **Fix:** apply a stated failure rule. Either any failure, or production's threshold at the reading's level, makes the reading "not computable" (the shift and SE still printed). Add a test.
