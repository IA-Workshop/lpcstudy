#### Job 1: answers to "Applied-mathematician must confirm"

**1. Joint bootstrap: confirmed [A, V].**
- Use one moving-block index array per resample per ρ for both parts of R(idx) = ½·`_fit_seed_law`(sizes, median of seed_sq[idx] by column)[0] / mean(inverse_dim[idx]). This carries the numerator–denominator covariance across states. The percentile interval of R is first-order valid: R is a smooth function of column medians and a mean (Hadamard-differentiable), and the states are weakly dependent (math note §5: |ACF| ≤ 0.08 at the coded spacing).
- Jensen bias of 1/mean is CV²/n = 0.229²/300 = 1.7e-4, which is negligible.
- Different index draws at the two ρ (separate seed labels) are fine. H1a needs both ρ to pass, an intersection–union test, so each per-ρ interval only needs to be marginally valid.
- The reference over the test-sweep states is right, because the `np.array_equal` guard makes it one state set for every cell.
- One thing must be explicit: the excluded-state set (item 5) applies to the numerator and the denominator together.
- Recommendation: compute `ci_inverse_dim` and `ratio_ci` in **one pass** with a vector statistic (contract below, `bootstrap_values`). The plan's second call with the same label is equivalent, but it doubles the 2000 curve fits.

**2. S/(k−1) unbiased for 1/d; T2 at 3%: confirmed [A, V]. This is stronger than the Poisson statement.**
- Condition on T_k = r for iid sampling from a density that is uniform on a d-flat, with the r-ball inside the support. The k−1 nearer points are then iid uniform in the ball. So −d·ln(T_j/r) are iid Exp(1), S·d ~ Gamma(k−1, 1), and E[S/(k−1)] = 1/d **exactly**, with no Poisson approximation. T2's interior-query sets satisfy these premises (the radius check is < 0.2).
- Inverting the existing k−2 `local_dim` gives S/(k−2), which is high by (k−1)/(k−2) − 1 = **+5.56%**.
- Simulated with 300 fresh seeds per m (seed `[4242, m, s]`, 20 000 reference points, 2000 queries, never seed 50053):

|---|---|---|---|---|---|---|---|
| 1 | +0.00003 | 0.00516 | 1.01 | 0.0156 | 5.8 | +0.0556, 5.0 | 0 |
| 2 | +0.00030 | 0.00508 | 0.98 | 0.0154 | 5.9 | +0.0559, 5.1 | 0 |
| 3 | −0.00002 | 0.00528 | 1.06 | 0.0147 | 5.7 | +0.0555, 4.8 | 0 |

**3. T1 design: the planned (σ = 0.5, floor = power term at the 4th size) FAILS both requirements [V]. Replace σ and f² as below.**
- Scan setup: 1000 to 2000 seeds per design, seed `[20261011, s]`, a verbatim copy of `_fit_seed_law`, 300 states, 5% × 100 inflation, noise and inflation drawn per (state, n_lib).
- Planned design (σ = 0.5, floor at 31 623): the median-fit relative error has SD 0.0364. So 5% is only **1.35 SD**, and P(|e| > 5%) = 0.17. The mean-fit miss probability is 0.83, below 0.9.
- Why: the free floor triples the SE from the planner's 1.2%. The mean fit's miss probability is set by the Binomial(300, 0.05) count of inflated states (log-mean SD ≈ 0.21 per column), not by σ. Only an earlier floor raises it, and that costs median precision, which forces a smaller σ.
- **Adopt: σ = 0.05, f² = b²·3162^(−2/2.2)** (the floor equals the power term at the **2nd** `library_sizes` entry). Over 2000 seeds:
  - median fit: bias +0.0001, SD 0.0088, so **5% = 5.7 SD**; max |e| = 0.030; P(|e| > 5%) = 0/2000;
  - mean fit: misses ±5% with **probability 0.920** (MC SE 0.006).
  - Runner-up: floor at 1778 gives 4.0 SD and power 0.94.
- The ±5% stays (ROADMAP). Choose the test's `default_rng` seed before looking at any output. The test asserts only the median fit. The mean-fit power is the probability of detecting a mean-for-median mutant, not an assertion: at power 0.92, asserting it at one seed would be flaky.

**4. Failed resamples at ±∞: confirmed as the reading of A3 for every band, two-sided or one-sided [A, V].**
- For a band, "unfavourable" depends on which verdict is at stake. Widening is unfavourable to both pass and fail: each failed value counts at −∞ for the lower quantile and at +∞ for the upper.
- One-sided placement is not safe. Placing all failures low moves *both* quantiles down, so it makes "fail" (upper < a) easier. Placing them high can likewise manufacture a fail on [0, 0.2).
- Exact edge: a bound is infinite iff the linear interpolation gives positive weight to a failed order statistic. With p = α/2, that is **F ≥ F\* = ⌊(B−1)p⌋ + 1**, the same threshold on both sides, so both bounds become infinite together.
- F\* equals ⌈pB⌉ (the "≥ α/2 of B" wording) for every case checked (0 mismatches against the exact index rule): B ∈ {20, 50, 200, 500, 2000} × level ∈ {0.8, 0.9, 0.95, 1−0.05/3}. Values: B = 2000 gives 50 (95%) and 17 (1−0.05/3); B = 500 gives 13 and 5.
- **Defect in T7(ii) as planned.** The reference "NaN → ∓1e300, beyond ∓1e299 → ±∞" fails. At B = 2000 and 95%, h = 49.975, so the failed order statistic gets weight 0.025 and `np.quantile` returns −2.5e298, which is not beyond −1e299. Replace it with the exact index rule above, computed in the test independently of the code.
- Also never feed ±inf to `np.quantile`: inf−inf in its lerp produces NaN (RuntimeWarning observed).

```python
                     n_resamples: int, block: int, seed: int | np.random.Generator

```

**Semantics.**
1. **`block_resample_indices`.**
   - `rng = seed` if it is a Generator (consumed), else `np.random.default_rng(seed)`.
   - Per resample: `starts = rng.integers(0, max(1, n−block+1), ceil(n/block))`; yield `np.minimum((starts[:, None] + np.arange(block)).ravel()[:n], n−1)`.
   - These are exactly the draws of `block_bootstrap`, in its order.
   - `block_bootstrap` is refactored onto it. Its return expression, including `np.nanquantile` and the point evaluated after the loop, stays the same, so its output is **bitwise unchanged**. Switching its callers to A3 is WU-0002.9/.11.
2. **`bootstrap_values`.**
   - It returns `(point, values)`: values have shape (B,) for a scalar statistic, or (B, q) for a 1-D length-q statistic (shared resamples, several quantities in one pass).
   - The point is `statistic(np.arange(n))`, evaluated **after** the resamples, as in `block_bootstrap`, so recorders see the same sequence.
   - Exceptions are not caught. A statistic signals "cannot compute" by returning NaN.
3. **`percentile_interval`.** It takes 1-D values; for (B, q), call it per column.
   - **Failed** = `~np.isfinite(value)`. Let p = (1−level)/2, F = the failed count and F\* = ⌊(B−1)p⌋ + 1.
   - If F ≥ F\*, including F = B, it returns (−inf, +inf, F).
   - Otherwise:
     - `lower = np.quantile(np.where(failed, finite.min(), v), p)`;
     - `upper = np.quantile(np.where(failed, finite.max(), v), 1−p)`.
   - This equals the quantile with failures at ∓∞, with no inf arithmetic, and is bitwise `np.quantile`/`np.nanquantile` when F = 0.
   - There is **no `unfavourable` argument**: widening is the unfavourable tail for every verdict.
4. **`block_bootstrap_counted`** = `bootstrap_values` + `percentile_interval`. With an int seed and F = 0, its (estimate, lower, upper) equal `block_bootstrap` bitwise.
5. **`interval_verdict`.**
   - band = (a, b) with a < b. a = −inf or b = +inf gives a one-sided bound. An infinite edge is always satisfied; `closed` applies to finite edges only. lower ≤ upper is required (else `ValueError`). A NaN endpoint gives inconclusive.
   - pass iff (a = −inf or lower ≥ a [closed] / > a [open]) and (b = +inf or upper ≤ b [closed] / < b [open]).
   - fail iff (a > −inf and upper < a [closed] / ≤ a [open]) or (b < +inf and lower > b [closed] / ≥ b [open]).
   - Otherwise inconclusive. Compare unrounded float64 values (A1).
   - v3 bands:

| Criterion | band | closed |
|---|---|---|
| H1a | (0.75, 1.25) | (T, T) |
| H1b | (0.8, 1.2) | (T, T) |
| H1c | (0.8, 1.25) | (T, T) |
| H1d | (0.7, inf) | (T, ·) |
| H2a(i) | (−inf, 0.1) | (·, F) |
| H2a(ii) | (−0.1, 0.1) | (F, F) |
| H2b, H2e, H3b D | (0, inf) | (F, ·) |
| H2c | (−inf, 0) | (·, F) |
| H2d | (−inf, 0.10) | (·, T) |
| H3c | (−inf, 1.05) | (·, T) |
| H3b weight | (0, 0.2) | (T, F) |
