**Scope.**
- **In:**
  - (a) `statistics.py`: `block_bootstrap_counted(statistic, n_items, n_resamples, block, seed: int | np.random.Generator, level=0.95) -> BootstrapInterval` (frozen dataclass `estimate, lower, upper, n_failed, n_resamples`). It shares one private resampling loop with `block_bootstrap`, whose output stays bitwise unchanged. A non-finite resample is *failed*: it is counted and placed beyond both endpoints (−∞ for the lower quantile, +∞ for the upper, linear interpolation over all B values; an endpoint that interpolates into a failed value is ±∞). This is DEC-0008 A3, "unfavourable tail", for a band: conservative for pass and for fail.

Only closed bands are used here. The strict form exists for WU-0002.9.
