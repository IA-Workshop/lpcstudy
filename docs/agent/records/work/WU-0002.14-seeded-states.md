### Scope

**In (a): start states (DEF-0017; Methods v2 change-list item 8; v3 "Same attractors, fresh seeds").** The changes are in `data.build_context` and a new pure function `data.draw_starts`.
- One generator `make_rng(seed, "start", system)` is consumed in a fixed order: k_main, u_main, k_est, u_est.
  - k is uniform on {0, …, 199 999}, an index into the post-burn-in statistics orbit.
  - u ~ N(0, I₃).
  - Start: s = stats[k] + η·C^{1/2}u. The default is η = 1e-6 (whitened units); the value is the AM's (M1).
- The **main** and **estimator** trajectories each start from their s and discard the unchanged 100-LT burn-in (`burn` steps).
  - Main no longer continues `stats[-1]`. The estimator start replaces `initial_state + 1e-3`.
  - Both are guarded as in WU-0002.11c.
- The **statistics** trajectory stays at the registry start (default; O1 and M2). So σ_x, C, τ_d, τ_ac, spacing and the layout stay system constants, identical for every seed. The Benettin orbit also stays at the registry start (λ is a system constant, cached by name).
- New `ctx.meta` leaves, giving 8 `context` leaves per system:
  - `start_index: {main, estimator}` (int);
  - `start_state: {main: [3], estimator: [3]}` (float).

**In (b): the conversions (DEF-0011, the R1 table of WU-0002.11, M7).**
- Rule: one label per criterion or purpose. Parts that share a stream today **within** one criterion keep sharing it (same label). Sharing **across** criteria or across systems is removed.
- Library functions take a `np.random.Generator` and callers build it, so no import edge changes.
