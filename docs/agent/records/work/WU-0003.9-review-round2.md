## Findings

**R14 (blocker, PRIME.2): a K difference in a robustness variant licenses 0.1 hw on the main system's K blocks.**

- **Where:** `tools/compare_runs.py:501` (`licensing_kind`: any `chosen_K` is K), `531-533` (`count_scope` returns `(system, "K")` for it), `548` (`in_scope`), `556` (`follows_k`), and `736` (one-sided leaves, `star=False` still matches `"K"`).
- **What happens.**
  - `loc(("robustness", s, variant, "chosen_K"))` is `(s, "robustness")`. `count_scope` returns `(s, "K")`, and `in_scope` then admits `systems/<s>/{fitted, H3a, H3c, regime_curve}`.
  - The real schema has `robustness/<s>/{base, D=5, D=10, k=5, misspec=0.05, misspec=0.1}/chosen_K` (P1).
  - Probe on real P1: `robustness/rossler/misspec=0.1/chosen_K` +1, and `systems/rossler/H3c/A5_over_A4_mse` moved by 0.5 x 0.1 hw. Under T1, T2 and T3 the H3c leaf **passes** ("discrete scope: 0.1 hw"). Without the robustness K change it FAILs (QoI rule).
  - The same scope lists differing integers of the main `H3a` and `regime_curve` (`follows_k`) and excuses one-sided leaves there.
  - The robustness variant's own leaves (`robustness/<s>/<variant>/H1b/*`) are *not* licensed by it, because their block is `robustness`, not a K block.
- **Why it matters.**
  - A robustness variant's K does not feed the main fit, so this is a scope wider than causal. It is the same class of defect as R1 (B1 item 3 keeps A6's "result block").
  - In a T1 to T3 pair that runs robustness (WU-0016 cross-host, or R1 against R1-like reruns), a K flip in one misspecification variant (plausible near a selection tie) would let the main H3c and H3a estimates move by 0.1 hw instead of 1e-4·s, while the RESULT reads PASS.
- **Fix.**
  - A K under `robustness/<s>/<variant>/` opens the scope `(s, "robustness")`, or better the variant subtree only, never `(s, "K")`.
  - `follows_k` and the one-sided rule should use the same scope.
  - Add a test with the real path `robustness/<s>/misspec=0.1/chosen_K`: the main H3c at 0.5 x 0.1 hw must FAIL, and a main `H3a` integer must FAIL.

**Developer's answer to R14:** fixed in b16cb79.
