### Scope

**In.**
- **Step 1, the tool `tools/compare_pilot.py`** (new, standard library only, no `lpcstudy` import).
  - **Reads** a new `results.json` and `docs/study/pilot_results_v1.json`. Leaves are addressed by `/`-joined paths, because keys such as `0.01` contain dots.
  - **Transforms the v1 paths to v3** with these rules:
    - `V1_TO_V3`, the decision-log correction table, applied to `systems/<s>/<key>` and to `verdicts/<key>`;
    - v1 `H3b/{regret_ratio_by_K, realized_K}` move to `regime_curve`;
    - `*_by_N` keys become `*_by_n_lib`;
    - `robustness/<s>/<variant>/H1c` becomes `H1b` (D-16);
    - leaves that moved with an unchanged value are compared as `unchanged`, for example H1d `spearman/<x>` → `rows/<x>/spearman` (.5). The developer pairs these from the "removed/new" lists of the sub-task Logs;
    - every `seconds` leaf is stripped and reported as wall-clock;
    - the new side's `provenance` is excluded.
  - **Classifies every leaf with an ordered rule table** (path glob → class, sub-task, §M15/DEC/concordance item, reason, expected direction, interval sibling and level, chain). The classes are:
    - `unchanged`: must be bitwise equal, or within the rule's `rel_tol`. `rel_tol` is 0 by default; 1e-12 is allowed only on a rule that cites a logged change of summation order;
    - `changed`: listed with the old value, the new value, the sub-task and the reason;
    - `new`: v3 only;
    - `removed`: v1 only;
    - `wall-clock`: not compared.
    A leaf that matches no rule, or two rules, is an error (exit 2) and is never classified silently (PRIME.4).
  - **Selects the branch** (bitwise or fallback) by the switch rule below. It evaluates the bitwise criterion, and the fallback criterion once its constants exist. Until the owner's DEC records them, it refuses the fallback (exit 3, naming the missing DEC).
  - **Writes** `docs/study/dev_regression_dev0.md` and a full per-leaf JSON under `runs/dev/wu0002-12/` (gitignored).
    - The report's first line is `DEVELOPMENT (DEV-0): not a hypothesis test`.
    - Every number carries its provenance: the commit, the run directory, the sha256 of both JSON files, the manifest row, and `LPC_THREADS`/`nproc`.
    - It has the tables of changed statistics (old, new, sub-task, item, reason), of failures, of removed groups (counted per group, not leaf by leaf) and of new checks, plus "things to look at".
  - **Tests** in `tests/unit/test_tools_compare_pilot.py` (T1 to T10).
- **Step 2, the run.** The pilot preset on CPU on DEV-0 through `tools/run_preset.sh` with `LPC_THREADS=8`, in the background (Execution).
- **Step 3, the comparison.** The tool run once on the output. The table goes into `docs/study/dev_regression_dev0.md` and a summary into the parent WU-0002 `## Log`.

**Out.**
- Any change to `lpcstudy/`. A difference found is a DEF plus `/refer`; it is not fixed inside this unit.
- The DEF-0011 conversions (.11d) and the DEF-0017 seed-dependent start states. Both change every number, so they come strictly **after** this run (DEC-0008 B, DEC-0017 Q7).
