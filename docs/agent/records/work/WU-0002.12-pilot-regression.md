  - **Transforms the v1 paths to v3** with these rules:

**Structural fact behind AM1, AM2 and AM4: there are two regimes and nothing between them.**
- `interval = 1/(30 λ)` (`data.py:262`). If λ differs by even one ulp, the RK4 step differs. A difference of 1e-16 grows at 1/30 per step and reaches O(1) after about ln(1e16)·30 ≈ 1100 steps. That is inside the 3000-step burn-in of the statistics trajectory, and the main trajectory starts from its end. The same holds if λ is equal but the RK4 arithmetic differs.
- **Regime N.** λ and interval are bitwise equal, every context integer is equal, and `obs_scale` is within 1e-12 relative. The trajectory, states, library, noise and CP are then the same. Only the network chain (ψ, the A3 `ErrorPredictor`) can differ, through XLA kernel rounding.
- **Regime D.** Anything else in `context` differs. The run is then a new realization of the whole study: new test states, new training data, and networks that differ at seed level. Its differences from the pilot are sampling variability, not numerical error.
- **Cache caveat.** λ is read from `<cache_dir>/lyapunov.json` if that file exists (`data.py:229`). A cached λ would hide a Benettin platform difference. The run must start without that file, or the tool must record the cache's origin.

**AM1. Recommend k = 5, closed: |λ_new − λ_pilot| ≤ 5·SE.** The bounds are Lorenz-63 0.0060, Rössler 0.00275 and Chua 0.0240. F2 applies only in regime D; in regime N, λ is bitwise equal by definition.
- **Model.** In regime D the two Benettin runs share the initial condition but diverge long before the Benettin burn-in ends: after about 41, 514 and 86 time units, against burn-ins of 1000, 4000 and 500. They are therefore two nearly independent time averages, so Δλ ≈ N(0, 2·SE²) by the CLT for the time average. The SE is the WU-0007 batch-means value for the same estimator, length and initial condition.
- **What k protects against.** It keeps a platform re-realization from being reported as a defect (false alarm), while still catching a change of the dynamics (a parameter, the step or the integrator).

- **Downstream propagation.**
  - **LM.** Its 15 iterations contract an initial-guess difference toward the same local minimizer. The converged estimate differs only by about eps·κ(A), unless the initial guess lies within about 1e-12 of a basin boundary, which has negligible probability.
  - **Forecasts.** e^{λt} amplifies the forecast difference, but it amplifies the error by the same factor, so before saturation the relative difference stays about Δu/δ.
  - **Statistics.** Smooth statistics inherit about 1e-9 relative or less. The median is 1-Lipschitz in the sup norm, and percentile bootstrap endpoints are Lipschitz in the resampled values.
- **Ways a 1e-12 perturbation can grow ("chain-head events").**
  1. **Discrete decisions.** These are threshold crossings (the realized horizon, the decisive set, the clip of w\*, the ν cap), `chosen_width` (the 5% rule), K (the 5% criterion), tree splits and `best_single`. In regime D, at seed-level differences of 5 to 15% in the validation loss, the Rössler 5% and 1% widths can flip.

If a stopping test flips, the output moves by the last step, up to about √ftol ≈ 1e-4 relative in a poorly determined direction. This is rare, but possible.

**AM3. The regret identity is confirmed, with stated hypotheses. The 1e-12 allowance is ample.**
- **Algebra.** Let u = (sq_plp − cross)/c and w\* = clip(u, 0, 1). Then old = c(w − w\*)² (v1) and new = c[(w − u)² − (w\* − u)²] (v3).
  - For u in [0, 1], new = old, and this is **bitwise** in IEEE arithmetic: `clip` returns u itself, so (w\* − u)² = 0.0.
  - For u < 0, new − old = 2c·w·|u|.
  - For u > 1, new − old = 2c(1 − w)(u − 1).
  - Both are ≥ 0, matching the plan's text.
- **Hypotheses** (H4 holds by construction; the others are checked as stated):
  - **H1.** w is bitwise unchanged. This holds in the bitwise branch; the regime-N extension is below.
  - **H2.** The moments (sq_cp, sq_plp, cross) are bitwise unchanged.
  - **H3.** 1e-300 ≤ c < ∞ on every scored entry, read from the `handling` counter `curvature_floor` = 0 on the test split. If c < 0 from cancellation, or u overflows, new can be below old or NaN. A failure of R3 there is attributed to that counted sentinel, not to a defect.
  - **H4.** w ∈ [0, 1]. This holds by construction: A0 = 1, A1 = 0, A2 is clipped, A3 is a sigmoid, and A4 and A4o are δ²/max(ε² + δ², 1e-300).
- **Floating point.** For u < 0, fl(w + |u|) ≥ |u|, so the computed new value is ≥ 0. A computed entry falls below old only when 0 < w < 4·eps·|u| (or the mirror case near w = 1). Its shortfall is then at most c·w² < 16·eps²·c·u², about 1e-31·c·u².
  - The mean over (n, E) uses the same pairwise order for both arrays, and rounding is monotone. The aggregate can therefore only fall short by the sum of those entries' shortfalls.
  - That exceeds 1e-12 of the old regret only if mean(c·u²) on those entries is more than 10¹⁸ times the old regret, which needs u near overflow.
- **Numerical check** (`am3_regret.py`): 300 synthetic moment sets with n = 500, E = 2, M = 200 and 5 horizons, five rule types including sigmoid tails at ±50, and an adversarial grid of 4e6 points.
  - 136 850 entries had new < old. All had w < 4·eps·|u|, and the largest shortfall was 1.2e-32·c·u².
  - No horizon aggregate had new < old (largest relative shortfall 0).
  - Every entry with u in [0, 1] was bitwise equal.
- **Recommended form of R3:** new ≥ old·(1 − 1e-12), one-sided, at every horizon, for A0 to A4 and A4o, and A\* = 0.0 exactly. In regime N, w differs by about 1e-12, so use new ≥ old·(1 − 1e-6) there.
- **Expectation, not a criterion:** a strict increase for A0 wherever a state has u < 0 (the pilot had 22 to 36% w\* = 0 at 1 LT), and for A1 wherever u > 1.

**AM4. "Inside the pilot's interval" is the wrong yardstick in both regimes.**
- **In regime N** it is far too loose. The predicted difference is about 1e-12, so a defect that moves a statistic by 90% of its half-width would pass.
- **In regime D** it is too strict, and it tests the wrong thing. For an independent replicate, P(new outside the old 95% interval) = 2Φ(−1.96/√2) = **0.166** per statistic, so with tens of statistics F3 fails almost surely.
- **Recommended formulation.**
  - **Regime N:** the 1e-6 relative class (AM2). A leaf above it passes only if a chain-head event lies upstream and, when the leaf has a pilot interval, |Δ| ≤ 0.2·SE_arm.
    - SE_arm is the arm of the pilot interval on the side of Δ (hi − est if Δ > 0, otherwise est − lo), divided by z(level).
    - z = 1.960 at 95% and 2.394 at 1 − 0.05/3. This removes the level dependence: it is 0.102 of the arm at 95% and 0.0835 of the arm at the primary level.
    - A change of one state in a median of 300 to 500 states moves it by about 1/√n ≈ 0.05 SE, so 0.2 SE allows about four flipped states.
    - The Monte Carlo error of the B = 500 percentile arms (6 to 8%) does not matter at this scale.
  - **Regime D:** re-reference (preferred; see the criterion text). If the owner declines, use a two-sample band |Δ| ≤ z_B·√(SE_old² + SE_new²), with each SE an arm divided by z(level) and z_B = Φ⁻¹(1 − 0.05/(2m)), Bonferroni over the m statistics that have intervals. Common noise seeds make the two runs positively correlated, which makes this test conservative.
- **Inclusion:** closed throughout (|Δ| ≤ bound). The edge has probability 0 for continuous statistics. Closed matches DEC-0016 and T7. For a degenerate arm (lo = est, for example an atom at 0), it correctly demands Δ = 0.
- **v1 levels.** The T8 tags are right: `H2a/range_ci`, H2a `partial_ci` and `H2b/noise/ci` are at 1 − 0.05/3, and everything else is at 0.95. The SE normalization makes the criterion level-free. The level is still printed per row.
