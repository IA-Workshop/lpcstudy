### Principle

**This unit only counts and reports.** No value in `results.json` outside `handling` changes, and no new key appears outside the paths listed in V1. A counter must not consume randomness or reorder any computation. Changing how a case is *treated* would change numbers, for example excluding replaced states, moving dropped resamples to the A3 tail, or failing a bound hit. Each such change is listed under "Questions for the owner" and goes to WU-0002.9 or to a later ruling.

### Schema of `handling` (decided once)

- **Per system:** `results["systems"][s]["handling"]` = `{schema: "lpcstudy.handling/1", cells, oracles, fitting, result_counts, totals}`.
  - **`cells[<id>]`** = `{counts, by_kind: {oracle, eval}, denominators}`.
    - `<id>` is `"<label>|rho=<g>|n_lib=<n>|core"`, or `"…|sweep"`, plus `"V4-convergence"` and `"V6-cp-horizon"`.
    - `counts` holds every counter of the cell set: `invariant_mean_replacements`, `nu_replacements`, `error_clips`, `error_clips_cp`, `error_clips_plp`, `error_clips_nonfinite`, `gain_replacements`, `gain_floor`, `zero_variance_corr`, `zero_variance_corr_cp`, `zero_variance_corr_plp`, `curvature_floor`, `decisive_floor`, `closed_form_floor`.
    - `denominators`: `estimates`, `error_entries`, `eval_draws`, `moment_entries`.
  - **`oracles[<split>]`**: `local_dim_zero_distance`, `oracle_gain_floor`, `oracle_nonfinite`; the denominator is `states`.
  - **`fitting`**: `regime_count_fallback`, `regime_count_fallback_by_K`, `pooled_curvature_floor`, `regime_target_constant`, `nu_cap_clips` (per split).
  - **`result_counts`**: `{json_path: int}` for every result key named in `RESULT_COUNT_KEYS`. It is a copy; the result key stays the authority.
  - **`totals`**: every counter name, as the sum over cells, oracles and fitting.
- **Per run:** `results["handling"]` = `{schema, totals, by_system, robustness: {s: {cells, totals}}, failed_variants}`.
  - Robustness handling is here and **not** under `results["robustness"][s]`, because `report.py:406-410` reads every key there as a variant.
- **Rules:**
  - Every counter is present, and zero is allowed. Counts are Python ints.
  - The cell set is recorded once, in `Study.run_cell`. `_sweep_subset` views are never recorded again.
  - Per-draw counters travel as an `(n, n_counters)` int array `handled` on `DrawBatch`, `EnsembleMoments` and `EvaluationDraws`, with the column names in `ensemble.DRAW_COUNTERS`. It defaults to `None`, so hand-built moments in the tests still work. `subset` and both `_concat_*` carry it, so a state subset carries its own counts.
  - The moments-derived counters (O2, P1, L4, E4) are computed from stored arrays. They need no instrumentation.
- **`run.log`:** one `WARNING` line per nonzero counter per block (`handling <system> <block id>: <counter> = <k> of <denominator>`), and one summary line per system. A zero counter writes no line.
- **No new module.** The schema and assembly go in `pipeline.py` (`Study.handling`, `cell_handling`), and the result walker and log go in `experiments.py`. So no import edge changes and the graph fixture is untouched. If the developer needs a new edge, the fixture and `test_tools_test_impact.py` change in the same commit.

  - Wrong-basin means ψ returned a finite state in a wrong local minimum, a property of the estimator (Judd 2003). A replacement means ψ returned nothing finite. The substituted invariant mean is an imputation.

- **M2 `error_clips`.**
  - *Bias.* The clip at 10 σ_x is part of the estimand (v3 §4), not an approximation. When divergence has positive probability, the unclipped E e_P² is +∞ (overflow) or larger than the clipped one.   - Per state, with a fraction q of draws clipped: E e_P² = (1−q)·E[e_P²|reg] + 100q. Exact, since |clip| = 10.

- **This is not a correctness or independence problem for the inference.**
  1. **The overall verdict is an intersection–union test** (v3 §7: supported only if every system passes). Its size holds under arbitrary dependence between the per-system tests (Berger 1982). "Not supported", meaning any system fails, is bounded by the sum of the per-system false-fail rates under any dependence. Positive dependence only lowers the union. The Bonferroni (H2a, H2b, H3c) and Holm corrections are also valid under arbitrary dependence.
  2. **The dominant variability is independent across systems** (different attractors and noise). Shared indices couple only the Monte Carlo error of the endpoints. Applied to independent data sets, the same indices give **uncorrelated** endpoint errors. `shared_idx.py` (AR(1) φ = 0.6, n = 1000, block 5, B = 2000, reference B = 20000, 300 pairs):
     - the endpoint MC error is 3–4% of the half-width;
     - the correlation across data sets with shared indices is 0.05 and 0.01 (mean), 0.06 and 0.02 (median), against a null sd of 0.058;
     - with independent indices it is 0.09 and 0.01.
  3. **No quantity in the study is a function of two consumers of the same stream.** The A3 network and Λ_fin directions never enter a salt-0 interval (V7, H1b-CP, H1c). V4 shares bits with salt 0 but answers a separate question.
- **What it is.** It breaks the `make_rng` convention, and it is a latent coupling risk if a future statistic combines two consumers.
