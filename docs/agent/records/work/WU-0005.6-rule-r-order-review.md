## Findings

### R1 (medium; correctness of M7, endpoint-limited label). The infinite-bound switch depends on the component set, so the point-only class and the label are wrong for an infinite bound at the 30 or 60 arm.
- **Where.** `tools/lm_doubling.py:328-336`. `values` and `infinite` use only `components`. `build_comparison` (`:784-786`) calls `classify` a second time with `components=("pt",)` and sets "endpoint-limited at B = ..." when the classes differ. The pairing blockers and `_structural` are passed to both calls, but the infinite bound is found only inside `classify`.
- **Evidence** (a direct `classify` trace on the branch, no test run; tail 0, hw 1):
  - `{15: [-1,1], 30: lo = -inf with verdict "inconclusive", 60: [-1,1]}`, pt 0 throughout: full **U**, point-only **X**, so the label is set. **This label is new with this change** (before, both were X).
  - `{30: pt 1/32, 60: pt 3/64 with hi = +inf}`, verdicts equal: full U, point-only **N** (pre-existing, same cause).
  - The infinite case also gets the same reason text as `hw <= 0` ("not computable: an endpoint is infinite or the half-width is not positive"). Since the two now lead to different classes, the report does not say which switch made the part U, although M7 requires the switches to be "reported".
- **Why it matters.**
  - M7: "an infinite bound (A3) at any arm" is a property of the part, not of the components entering d1. A part with an M7 switch is U for every component set.
  - The endpoint-limited label (M2) is meant to attribute a class difference to bootstrap endpoint noise. Here it would attribute a structural switch to that noise instead.
  - In the other direction, the code treats an infinite **point** with finite bounds as an "infinite bound". This is slightly wider than the text. It is harmless, but it is not what M7 says.
  - Not triggered on DEV-0 (no infinite value; the re-run is byte-identical apart from Chua H3c).
- **Required fix.**
  - Detect an infinite `lo` or `hi` at any arm independently of `components`, either in `_structural` (passed to both calls as a structural reason with its own text, e.g. "infinite bound (M7) at the 30 arm") or inside `classify` over `("lo", "hi")` of every arm.
  - Decide and record whether an infinite `pt` counts. It is not in M7, so keep it under the hw/NaN rule unless the owner says otherwise.
  - Add hand cases: an infinite `lo` at arm 30 with a verdict change, and an infinite `hi` at arm 60 with equal verdicts, under both `components` sets (U and U), plus one `build_comparison` case showing that no endpoint-limited label is set.
  - Correct the `_structural` docstring ("they make the class not N"; it is now U).
