### Scope

**In.**

It returns `"supported"` only if every system in `required` is present and passes. Otherwise it returns `"inconclusive"`, together with the list of required systems that are missing. `required` is the three v3 systems (lorenz63, rossler, chua); see O1. `combine_verdicts`, `interval_verdict` and `criterion_verdict` are unchanged.

The bootstrap moves from `_boot` to `block_bootstrap_counted` with the **same integer seed** (`config.seed + salt`). That is bitwise-equal when no resample fails (DEC-0012). It adds `n_failed_resamples`.

### Applied-mathematician must confirm before execution
The logic is combinatorial and fully testable by enumeration. Check:
- **(a)** that `block_bootstrap_counted` at the same integer seed is bitwise-equal to `_boot` for H1c, H2c and H2d. None of them can produce a non-finite resample (finite ratios, MSE > 0).

- **(d)** the overall rule when a v3 system is missing (O1).
