*Algebra (P1(a), P3(a)): correct.* V(w) = w²E_C + (1−w)²E_P + 2w(1−w)C = c w² − 2b w + E_P, with c = E_C + E_P − 2C and b = E_P − C. So V(w) = c(w − u)² + V(u), with u = b/c and V(u) = E_P − b²/c = (E_C E_P − C²)/c ≥ 0. If c > 0 (P1(a): c ≥ ρ²/k), w\* = clip₀¹(u) and excess(w) = c[(w−u)² − (w\*−u)²] = c(w − w\*)(w + w\* − 2u) = (w − w\*)(c(w + w\*) − 2b). If u ∈ [0, 1], this is c(w − u)². If u > 1 (w\* = 1), it is c(1−w)² + 2c(1−w)(u−1) ≥ c(w − w\*)², and symmetrically for u < 0. So c(w − w\*)² underestimates the excess exactly when u is clipped and w ≠ w\* (DEF-0002). P3(a): Σᵢ Vᵢ(w) = S_c(w − ū)² + const, with S_c = Σcᵢ > 0 and ū = Σbᵢ/Σcᵢ = Σcᵢuᵢ/Σcᵢ. A strictly convex 1-D quadratic is minimized on [0, 1] at the projection of its vertex, so w_S = clip₀¹(ū): **sum, then clip**. ū is a c-weighted mean of the *unclipped* uᵢ, so it lies in [min uᵢ, max uᵢ] and can leave [0, 1] (always when every uᵢ > 1 or every uᵢ < 0). Counterexample to the old clipped mean (DEF-0003): c = (1, 1), u = (−3, 2). Then ū = −0.5, so w_S = 0 with ΣV − const = 13. The old weight is 0.5, which gives 14.5.
