It returns `seed` unchanged if `0 <= seed < 2**32`. Otherwise it returns `int(make_rng(seed, "sklearn", label).integers(0, 2**32))`. It raises `ValueError` if `seed < 0`. 2. **H2a(ii), two parts (amended per DEC-0008 A4(a) and (a2)).**
   - Target: w* = `oracle_weight(m)[:, m.at(H_ref)]`, clipped to [0, 1], with no clip constant.
   - Controls: Q(x) = [x₁, x₂, x₁², x₂², x₁x₂], where x = (ln(ε_s/ρ), ln(δ/ρ)) is centred on the full-sample mean. Centring leaves the span unchanged. The intercept is added by `partial_correlation`.
   - Part (ii-a): `partial_correlation(1{w*=0}, Λ̃, Q)` over all test states.
   - Part (ii-b): the same with logit w* over the states where 0 < w* < 1.
   - Part (ii-c): 1{w*=1} over all states, added only if `20 * n_w_one > n_test` (strictly more than 5%).
   - Every part is at level 1 − 0.05/3 and uses the same resample index sets (same seed and salt 2). Domain filters are applied inside each resample, over all test states in time order.
   - Band verdict (A1, open band): pass iff lo > −0.1 and hi < 0.1; fail iff hi ≤ −0.1 or lo ≥ 0.1; otherwise inconclusive.
   - A part with fewer than 50 states in its domain, or with a NaN estimate, is inconclusive and its reason is recorded (A3).
   - (ii) passes iff every part passes, and fails iff any part fails.
3. **H2a(i), initial segments (amended per DEC-0008 A4(b)).**
   - L = the number of leading horizons in (1, 2, 4) LT at which both r.m.s. errors are ≤ `linear_regime_rms`. A state is eligible iff L ≥ 2. Its range is taken over the first L horizons.
   - Statistic: `median(range[idx][eligible[idx]])`. The bootstrap runs over all test states at level 1 − 0.05/3, salt 1, so eligibility is re-evaluated in each resample.
   - Reported: the median and count per span ({1,2} and {1,2,4}); the excluded count; the count of non-contiguous states that the v1 rule admitted.
   - Sensitivity: the complete-case median, which equals the median of the {1,2,4} span by construction, with its interval.
   - Verdict: pass iff hi < 0.1; fail iff lo ≥ 0.1. Fewer than 50 eligible states makes it inconclusive.
   - H2a combines (i) and (ii) by the multi-part rule. `pass` is `verdict == "pass"`.
4. **Q-N (amended per DEC-0008 A4(a); v3 §7; M2 E3; D-04).**
   - New module-level functions: `qn_regressor(random_state) -> HistGradientBoostingRegressor` and `delta_r2(y, pred_three, pred_four, idx) -> float`. The regressor has `max_iter=300`, `learning_rate=0.05`, `max_leaf_nodes=15`, `min_samples_leaf=20` and `l2_regularization=1.0`. A docstring note records `l2_regularization` (A4(c)). It also sets `early_stopping=False` explicitly, which at n ≤ 10⁴ is the same as 'auto'.
   - Targets:
     - logit w* fitted on interior states only, trained on interior construction and calibration states;
     - 1{w*=0} fitted on all states, by squared loss, so R² is the Brier skill score;
     - log horizon, reported without a reading (D-04).
   - Both profiles are computed: oracle (primary) and deployable (secondary). Intervals are 95%, salt 11, with shared resamples.
   - The new function `qn_reading(lower, upper) -> str` applies the v3 §7 table to the interior and indicator targets of each profile.
   - `noise_sens_r2_from_three` is kept. The keys `margin`, `verdict` and `pass` are removed, because Q-N is an estimate.
5. **Failed resamples (A3), an additive change to `statistics.py`.** Add `block_bootstrap_values(...) -> (point, values)` and `percentile_interval(values, level, failed) -> (lo, hi, n_failed)`. `block_bootstrap` is refactored onto the shared index generator, and its outputs stay bitwise identical. NaN resamples are placed at the unfavourable tail per Q-A4.

**Synthetic models for T9** (the planner's reconstruction; the note's scripts were not kept, REPRO.10).
- x ~ N(0, [[1, .5], [.5, 1]]); z, e, η and g are iid N(0, 1).
- Λ̃ = 0.5x₁ − 0.3x₂ + z.
- Interior logit L = 2(x₂ − x₁) + β_I z + 1.2e.
- Hurdle index h = 0.8x₁ − 0.4x₂ + β_Z z + η; w* = 0 iff h > c₀, where c₀ = Φ⁻¹(0.7)·sd(h) (30% zeros).
- Otherwise w* = 1 iff g > Φ⁻¹(0.98), about 1.4%; otherwise w* = sigmoid(L).
- **S0:** β_I = β_Z = 0.
- **S1:** β_I = 0.447, so the latent partial correlation is 0.349.
- **S2:** β_Z = 0.5, so the (ii-a) correlation is about 0.32.
- **S0n:** S0 with +0.6(x₁² − 1) added to Λ̃, h and L. Λ̃ is then exactly in span[1, Q] + z, so its population value with quadratic controls is exactly 0.
