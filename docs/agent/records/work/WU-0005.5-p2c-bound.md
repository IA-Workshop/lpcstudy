### Notation (as in the code; the mathematician confirms in .5a)

Per state: clean query x = G(s) (`delay_vectors(ctx.eval_clean, …)`), library vectors X_j = the noisy admissible delay vectors in `AnalogLibrary.tree.data`, r₁ ≤ r₂ the two smallest distances from x (`library.query(x, 2)`), i₁ the nearest, Δ = r₂ − r₁. Draws r = 1…M: η_r = ρ z_r with z_r the core cell's oracle `unit_noise`; Y_r = the k = 1 analog retrieved for x + η_r.

- **N_M** = `retrieval_spread(Y, ρ)`, the code's N, unchanged (Ȳ = empirical mean over the M draws).
- **A_M** = (ρ²D)⁻¹ mean_r ‖Y_r − X_{i₁}‖²: the spread about the clean analog (the proof's middle term).
- **B_M** = 4(ρ²D)⁻¹ mean_r (r₁ + ‖η_r‖)² 1{‖η_r‖ ≥ Δ/2}: the P2(c) bound on the same draws.
- **B_∞** = the same with the expectation over η ~ N(0, ρ²I_D) in closed form: 4(ρ²D)⁻¹[r₁²G₀ + 2r₁ρG₁ + ρ²G₂], G_j = E[χ_D^j 1{χ_D ≥ Δ/(2ρ)}] = 2^{j/2} Γ((D+j)/2)/Γ(D/2) · Q((D+j)/2, Δ²/(8ρ²)), Q = `scipy.special.gammaincc`.

In exact arithmetic N_M² ≤ A_M ≤ B_M for every state and every M (Huygens, then the per-draw triangle inequality and P2(a)). So on the same draws a violation is a defect, never a tolerance.

#### Proof check of P2 (v3 §3, Methods v2 §M9)

Write q = x + η. Let Y(η) be the library vector that minimizes ‖X_j − q‖, and i₁ the argmin of ‖X_j − x‖.

1. **(a) is correct.** It needs Δ > 0. For j ≠ i₁, ‖X_j − q‖ ≥ r₂ − ‖η‖ > r₁ + ‖η‖ ≥ ‖X_{i₁} − q‖ whenever ‖η‖ < Δ/2.
2. **(b) is correct.** It is Markov's inequality on ‖η‖², and this is the only place E‖η‖² = Dρ² is used.
3. **(c), per-draw step: correct for every η.** Y is the argmin, so ‖Y − q‖ ≤ ‖X_{i₁} − q‖ ≤ r₁ + ‖η‖. Then ‖Y − X_{i₁}‖ ≤ 2‖X_{i₁} − q‖ ≤ 2(r₁ + ‖η‖). By (a) the left side is 0 when ‖η‖ < Δ/2. So, pointwise, ‖Y − X_{i₁}‖² ≤ 4(r₁ + ‖η‖)² 1{‖η‖ ≥ Δ/2}.
4. **(c), the mean step: correct.** For any law of η, Var(Y) ≤ E‖Y − X_{i₁}‖² (Huygens). Divide by ρ²D.
5. **Ties.** With Δ = 0 the indicator is identically 1, and step 3 still holds. So (c) holds for Δ ≥ 0, with either choice of i₁ (both are at distance r₁). The theorem's "r₁ < r₂" is needed only for (a).

**Consequence.** (c) does not use the law of η. Applied to the empirical law of the M draws, it gives N_M² ≤ A_M ≤ B_M exactly, for every state and every M. This is the theorem itself, not an approximation of it. Huygens about c = X_{i₁} gives the identity N_M² = A_M − ‖Ȳ − X_{i₁}‖²/(ρ²D), which holds exactly.

#### M2. Expectation: option (c)

**Pass/fail uses B_M (same draws).** It is deterministic, and the pass condition is zero violations.

**B_∞ is report-only.** E[B_M] = B_∞ exactly (unbiased), and the Monte Carlo law is:

Var(B_M) = (16/(ρ⁴D²M)) · [Σ_{k=0..4} C(4,k) r₁^{4−k} ρ^k G_k − (r₁²G₀ + 2r₁ρG₁ + ρ²G₂)²].

Here G_k is as in M6, up to k = 4. Simulation (20 000 replicates of M = 200, four (r₁, Δ/ρ) pairs [S]) gives sd ratio 0.995 to 1.004 and |z(mean)| ≤ 0.76.

**Population count N_M² > B_∞.** There is no closed form for the expected count, and it is not small:

- Since N_M² ≤ B_M, an exceedance needs B_M > B_∞, which is an upward fluctuation.
- In the rare-switch regime (M·p_switch ≲ 1), B_M is 0 with high probability. When a single switch occurs, B_M ≈ B_∞/(M·P(χ ≥ t)) ≫ B_∞.
- So states with p_switch ≲ 1/M produce exceedances with probability ≈ M·p_switch. On Lorenz [S] at ρ = 1%, 2 of 1400 states had N_M² > B_∞.

**Decision.** Do not report this count; it has no pass/fail meaning. Report instead:
- the aggregate ratio ΣN_M²/ΣB_∞. Its expectation is at most (M − 1)/M times the population ratio, which is at most 1. Lorenz [S]: 0.043 at ρ = 1% and 0.077 at ρ = 5%.
- z_B = (ΣB_M − ΣB_∞)/√(ΣVar(B_M)), a check of the draws' law. Lorenz [S]: 1.03 and 1.26. It is report-only, and |z_B| ≲ 3 is expected.

The (M − 1)/M bias of N_M² is conservative for every population comparison and irrelevant for the same-draws check.

#### M4. Floating-point slacks: κ = 1×10⁻¹³; τ_N = M·u·max_{r,i}|Y_{r,i}|/ρ per state, with u = 2⁻⁵³

**τ_N.**
- `mean(axis=-2)` is a sequential sum of M terms followed by a division. The error per coordinate of Ȳ̂ is at most M·u·max|Y|. So the centring error is ‖δ‖ ≤ √D·M·u·max|Y|.
- By Huygens about Ȳ̂, the computed N̂² equals N_M² + ‖δ‖²/(ρ²D), times (1 + O((D + log₂M)u)).
- Hence N̂² ≤ A_M(1 + κ) + τ_N², and τ_N is a rigorous first-order bound. The planner's formula is confirmed, taken per state.
- Numbers:
  - At ρ = 0.01 and max|Y| ≈ 2.3, τ_N ≈ 5.2·10⁻¹² at M = 200 and 7.7·10⁻¹³ at M = 30 (smoke).
  - Observed worst residue / τ_N: 0.149 at M = 200 and 0.151 at M = 30, over 2·10⁴ random constant vectors [S].
  - The largest non-switching N on Lorenz [S] is 4.7·10⁻¹³, against τ_N = 5.2·10⁻¹².

**κ.**
- Each computed distance has relative error ≤ (D/2 + 2)u ≈ 6u: a positive sum of D squares, then a square root.
- η̂ = ‖fl(q − x)‖ has relative error ≤ 5u.
- Hence Δ̂ = r̂₂ − r̂₁ has *absolute* error ≤ 6u(r₁ + r₂).
- A float argmin can disagree with the exact argmin only when d_j − d_{i₁} ≤ 12u·max(d).
- Combined: switch ⇒ η̂_r ≥ Δ̂/2 − s_r, with s_r = κ(r̂₂ + η̂_r), against a first-order bound of about 20u(r₂ + ‖η‖). κ = 10⁻¹³ ≈ 450u gives a margin of 22×.
- Every other comparison is relative and needs (1 + κ) per factor.
- Any genuine defect shows at relative size about ρ/S ≥ 10⁻³.

**The checks, exactly as they are to be implemented.** Per draw r of state i:

| Key | Condition that must hold |
| --- | --- |
| `p2a` | switch_r := (pos_r ≠ i₁) ⇒ η̂_r ≥ Δ̂/2 − s_r |
| `triangle` | ‖Y_r − X_{i₁}‖ ≤ 2(r̂₁ + η̂_r)(1 + κ) |
| `consistency` | \|‖q_r − Y_r‖ − d̂_r\| ≤ κ·max(‖q_r − Y_r‖, d̂_r) per draw, and \|‖x − X_{i₁}‖ − r̂₁\| ≤ κ r̂₁ per state |

Per state, with c = 1/(ρ²D):

- B⁺_M = 4c·mean_r (r̂₁ + η̂_r)² 1{η̂_r ≥ Δ̂/2 − s_r}. This is the band-safe bound used for checking; B_M (the theorem's indicator) is used for reporting.
- `N_le_A`: N̂² ≤ A_M(1 + κ) + τ_N².
- `A_le_B`: A_M ≤ B⁺_M(1 + 4κ).
- **Headline:** N̂² ≤ B⁺_M(1 + 5κ) + τ_N².

`n_violations` = the number of states failing the headline or any chain item. `n_band_draws` = #{|η̂_r − Δ̂/2| ≤ s_r}; about 10⁻¹² is expected per draw, so 0 is expected.

**Relation to the plan.** The plan's P2(a) form, ‖η‖ ≥ (Δ/2)(1 − κ), scales the slack by Δ. Round-off in Δ̂ scales with r₂, not Δ: on Lorenz [S], 1% of states have Δ/ρ < 0.025 against r₁/ρ ≈ 5.7. So the relative-to-Δ form is not justified; see amendment A1.

#### M5. U2 and U3: keep the exact N == 0.0 in U2

**U2 (dyadic).**
- Sums of up to 200 copies of a multiple of 2⁻⁴ are exact. The correctly rounded division then returns that multiple exactly, so the centred values are exactly 0.
- Result [S]: N = A = B = 0.0, with max‖η‖ = 0.091 ≪ Δ/2.

**U3 (generic).**
- A_M == B_M == 0.0 holds exactly, since Y_r is bitwise X_{i₁} and every indicator is 0.
- N ≤ τ_N. Observed [S]: N = 1.5·10⁻¹⁴ against τ_N = 5.0·10⁻¹³.
- U3 is an added check, not a loosening: U2 keeps the exact zero, and U3 covers the generic coordinates that U2 cannot.
- Its premise must be the slack-safe one: max_r η̂_r < Δ̂/2 − max_r s_r.

#### M6. B_∞ closed form, and U1

**Formula (confirmed).** Substitute s = c²/2 in the χ_D density. This gives

G_j = E[χ_D^j 1{χ_D ≥ t}] = 2^{j/2}·Γ((D + j)/2)/Γ(D/2)·Q((D + j)/2, t²/2), with t = Δ/(2ρ),

B_∞ = (4/(ρ²D))·(r₁²G₀ + 2r₁ρG₁ + ρ²G₂).

Use `scipy.special.poch(D/2, j/2)` for the Γ ratio and `gammaincc` for Q.

**U1.**
- **Reference.** `quad` of (r₁ + ρc)²·f_D(c), with the density in log form, `epsabs=0` and `epsrel=1e-13`. Split [t, ∞) at max(t, √(D − 1)), at 12 and at 40.
- **Grid.** (r₁/ρ, Δ/ρ) ∈ {0, 1, 10} × {0, 0.5, 2, 8, 16}. Δ/ρ = 16 is added to exercise the far tail, where Q ≈ 10⁻¹⁰.
- **Tolerance: 10⁻¹² relative** (tightened from 10⁻¹⁰). Observed worst 2.5·10⁻¹⁵ [S], and quad's own error estimate is ≤ 8·10⁻¹⁴.
- **Δ = 0.** G₀ = 1 and G₂ = D within 10⁻¹⁴. Observed: exactly 0.0.
