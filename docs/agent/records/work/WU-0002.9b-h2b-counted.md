Checks:

- **Correctness.** Part (i) of `h2b_knob_response` (analysis.py:1455-1467) calls `block_bootstrap_counted` at the integer seed `config.seed + 3`, with `PRIMARY_LEVEL` and `config.bootstrap_block`. These are the arguments `_boot(..., salt=3)` passed to `block_bootstrap_dropped`. `criterion_verdict` is unchanged, with band `(0, inf)` and the lower edge open. It now receives the A3-tail bounds, and at both bounds infinite it returns `inconclusive` with the reason "failed resamples >= threshold". `_combined_decision` (analysis.py:1513) then gives an inconclusive H2b unless (ii) fails. The import already existed, so the import graph and the test-impact fixture are unchanged; only the three files above differ.
- **Bitwise equality when nothing fails.** Both paths draw the resample indices from `block_resample_indices(n, B, block, seed + 3)` with the integer seed. Both evaluate the B resamples first and the point estimate last, and both store float64. `np.nanquantile` on an array with no NaN reduces to the same linear-interpolation quantile as `np.quantile`, and `percentile_interval` takes the `np.quantile` branch at F = 0. So the intervals are equal bitwise. The test pins this against the old body and a hand `np.nanquantile` loop. The old body reuses `block_bootstrap_dropped`, but the hand loop is independent for the quantile step, so the test is independent enough. Exact comparison is justified.
- **Thresholds.** The test has B = 200 (`CONFIG`) and level `1 - 0.05/3`, so a = 0.05/6 = 0.0083333…, (B-1)a = 1.6583, the floor is 1, and the threshold is 2. This matches DEC-0012 and `percentile_interval` (statistics.py:321), and the test asserts it from the configured values rather than a literal.
- **Whether the tests discriminate.**
  - If the code reverted to dropping: in the NaN case at F = 2, `np.nanquantile` over the 198 remaining values gives [1, 1] and "pass", so the `inconclusive` assertion fails.
  - In the ±inf cases, the old count (NaN only) is 0, not 2.
  - In Part A, the bounds over 199 values differ from the 200-value A3 bounds.
  - The red run (4 failed before the change) is logged.
  - The injection wraps only the first `block_bootstrap_counted` call, at statistic call k = 7, which is a resample and not the point estimate.
