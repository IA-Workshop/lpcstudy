  - **R2 (medium; correctness of a stored diagnostic).**
    - **Where:** `lpcstudy/estimation.py`, `GOF_DEGREES = 4`, used in `lm_summary` (`fraction_above_chi2`).
    - **Why it matters:** the χ²₄ threshold assumes D − m = 4, that is D = 7. Every robustness variant `D=5` and `D=10` (`config.robustness_dims = (5, 7, 10)`, `experiments.py:565`) records an `lm` block through the same `cell_handling`.
      - For D = 5 (χ²₂), P(c/ρ² > 18.47) = 9.8·10⁻⁵.
      - For D = 10 (χ²₇), it is 1.0·10⁻².
      - So the leaf's stated meaning ("about 0.001 plus the unconverged and wrong-basin estimates") is wrong by a factor of 0.1 to 10. Smoke (`robustness_dims = (7,)`) does not show it.
    - **Fix:** pass the cell's D − m to `lm_summary` (via `cell_handling` and `check_record`, from `ctx.embed_dim` and `spec.dim`), compute the threshold as `chi2.ppf(0.999, dof)`, and store it (e.g. `gof_dof`). Alternatively, set the key to None when D ≠ 7, and document that. Add one hand test with dof ≠ 4. The applied-mathematician should confirm.
