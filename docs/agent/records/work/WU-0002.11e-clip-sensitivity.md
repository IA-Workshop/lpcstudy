### 1. Definition

**Notation.**
- L = `ERROR_CLIP` = 10 (units of σ_x; `ensemble.py:33`).
- H_ref = 30 steps, one Lyapunov time.
- `clip_errors` (`ensemble.py:110-144`) returns e_C = clip(cp − truth, ±L) and e_P = clip(nan_to_num(plp − truth, nan=+L, ±inf → ±L), ±L).
- D1 (`dynamics.py:50`) folds every non-finite PLP value into +inf. So a clipped PLP entry is either non-finite, stored as +L, or finite with |raw| > L, stored as sign(raw)·L.
- For a clipped PLP entry write e_P = σL, with σ = +1 for a non-finite raw value and σ = sign(raw) otherwise.
- C is the set of clipped PLP entries at H_ref of a computation. The per-state counts q_i = `error_clips_plp_href` + `error_clips_nonfinite_href` are already in `handled` (columns 4 and 5 of `DRAW_COUNTERS`, `ensemble.py:64`).

**The perturbation P₂.** Every clipped PLP entry at H_ref, in every split and cell that feeds the statistic, moves from σL to σ·2L. Everything else is held fixed:
- the states;
- the draws;
- the unclipped entries;
- the proxies (A4, A4o);
- the A3 network;
- the regime tree, its assignment of draws to regimes, and the chosen K;
- the bootstrap resample indices.

P₂ produces the value the same code would give at clip level 2L for every entry whose raw value is non-finite or has |raw| ≥ 2L. For a finite raw value in (L, 2L) it is the extreme case. Raw values are not stored, and the bound can only make the flag fire more often.

**Clip sensitivity of a verdict.** Let T be the verdict-bearing point estimate and [lo, hi] its interval at level α, both as computed today.
- T₂ is T recomputed under P₂.
- [lo₂, hi₂] and verdict₂ come from the same procedure under P₂, with the same resample indices. The integer seeds and `make_rng` labels are rebuilt fresh, so no stream advances (DEC-0012).
- The clip sensitivity is **Δ_T = T₂ − T**, on T's own scale.
- The scale is the half-width **hw_T = (hi − lo)/2** of the reported interval.

**Why a doubling, and only upward.**
1. "Without clipping" is undefined. D1 maps a diverged PLP orbit to +inf, so E e_P² = ∞ whenever divergence has positive probability (WU-0002.11 M2).
2. The clipped second moments are lower bounds of the unclipped ones. The only meaningful alternatives are therefore larger clip levels.
3. A halving (5 σ_x) would clip regular on-attractor errors. Lorenz-63 x/σ_x spans [−2.43, 2.47], so |e| reaches 4.9 + 4ρ. That changes the estimand for regular states instead of probing the treatment of divergence.
4. For a pure-PLP second moment (w = 0) the doubling gives the closed form ΔM = 3·Σ_C e_P²/(nE) = 3s·M. This is DEC-0017's "3s", which becomes a special case.

**Hypothesis H-CP.** `error_clips_cp == 0` in every input. CP clips are a sentinel: |e_C| ≤ 4.9 + 4ρ < L, WU-0002.11 (1). If H-CP fails, the clip sensitivity is not computed: `status = "not_computed"`, with `reason = "CP clip sentinel nonzero"`. Nothing is invented.

**Exact update formulas (P₂), verified numerically.** All use the stored clipped values.
- *Evaluation draws (per entry).* e_P ↦ e_P + σL on C. For a rule with weight w the hybrid error h = w e_C + (1−w) e_P changes by (1−w)σL, and

  h₂² − h² = 3(1−w)²L² + 2w(1−w)σL e_C.

  This is **not** bounded by 3h². Counter-example: w = ½, e_C = −5, σ = +1 gives h² = 6.25, h₂² = 56.25, Δ = 50 = 8h² (checked). So 3s is a descriptor of the share, not a bound on Δ for hybrids. The flag therefore uses the recomputed Δ_T.
- *Oracle moments (per state, at H_ref).* With q_i as above and χ_i = (1/M)·Σ_{r∈C_i} σ_r e_{C,ir}:

  sq_plp′ = sq_plp + 3L²q_i/M,  cross′ = cross + Lχ_i,  sq_cp′ = sq_cp (under H-CP),

  and then c′, b′ = sq_plp′ − cross′, w*′ = clip(b′/c′, 0, 1). For the pooled weights, A2′ = clip(Σb′/Σc′) over construction states, and A5′_k = `regime_weight` on the calibration moments with the members unchanged. An empty regime takes the fallback A2′, as the code does.
  - Check: 50 states, M = 200, with injected +inf, −37, 25, +inf and −1e9 entries, against a direct `clip` at 2L. sq_plp agrees to 2.1e-16 relative, cross to 1.4e-17 absolute.
- *H1b* needs only the counts: y_i′ = ½ ln(sq_plp_i + 3L²q_i/M). No new array.

**New internal arrays (not result leaves).** Both are written in `forecast_draws` from the masks it already computes (`ensemble.py:412-423`). Both refer to H_ref only, so they survive `_sweep_subset` and are sliced by `subset` (D1 option (b) of WU-0002.11).
- `EvaluationDraws.clip_sign_ref`: int8, shape (n, E), values σ or 0.
- `EnsembleMoments.clip_cross_ref`: float64, shape (n,), the χ_i above.

Consistency, asserted in a test: Σ_r |clip_sign_ref[i, r]| equals the handled H_ref columns of state i.

### 3. The share s and the scale, per verdict

The **descriptor** of the evaluation channel is the share of rule R's pooled squared error at H_ref on the test evaluation draws that comes from clipped draws:

  s_R = Σ_{(i,r)∈C} h_R,ir² / Σ_{(i,r)} h_R,ir², for R ∈ {A0, A1, A2, A3, A4, A5}.

For w = 0 (A1), ΔM_A1 = 3 s_A1 M_A1 exactly. The fitting channel is described by the weight shifts ΔA2 = A2′ − A2 and max_k |A5′_k − A5_k| at H_ref. The oracle channel is described by n_aff, the number of states with q_i > 0 among the statistic's input states.

The **compared quantity** is Δ_T, and the **scale** is hw_T of the verdict's own interval:

| Verdict | Δ_T on the scale of | hw_T from |
| --- | --- | --- |
| H2c, each decided part | the mean paired MSE difference (σ_x²) | that part's 95% `ci` |
| H2d | the excess ratio, mean(a_A4)/mean(a_A3) − 1 | its 95% `ci` |
| H3c | the MSE ratio | its 1 − 0.05/3 `ci` |
| H1b | the PLP slope | `PLP.ci` (95%) |
| H2a(ii), each part | the partial correlation | that part's `ci` (1 − 0.05/3) |
| H2b(i), H2b(ii) | the mean Spearman correlation; the mean change in w* | their `ci` (1 − 0.05/3) |
| H2e, each ρ | the median change; Δ is replaced by the bound below | its 95% `ci` |

**H2e bound (tier B).** Let d_(1) ≤ … ≤ d_(n) be the per-state differences, and let a be the number of states with q_i > 0 in either cell of the pair. Changing at most a values of the sample:
- odd n = 2m+1: the median stays in [d_(m+1−a), d_(m+1+a)];
- even n = 2m: it stays in [(d_(m−a) + d_(m+1−a))/2, (d_(m+a) + d_(m+1+a))/2].

An index outside 1..n is replaced by the range limit ∓2, since r ∈ [−1, 1]. Δ̄ is the larger distance from the median to these limits. There is no verdict₂ for H2e.

**H2c best single.** best₂ comes from the calibration MSEs under P₂ (calibration evaluation draws, `clip_sign_ref`). If best₂ ≠ best, then for the second part Δ = None and the part is flagged with `reason = "best single changes at 2L"`. The two parts no longer compare the same rules.

### 4. The flag rule and what is reported

For each tier-A or tier-B verdict part:

  **flag = (10·|Δ_T| > hw_T) or (verdict₂ ≠ verdict)**

- The inequality is strict. It is written multiplied out, so the edge is exact in floating point.
- If hw_T is not finite (failed resamples at the A3 tail), only the second clause applies and `ratio = None`.
- If hw_T = 0 (degenerate interval), the first clause reads Δ_T ≠ 0.
- If T or T₂ is not finite, or the part is not computable, then `status = "not_computed"` with a reason, and the flag is absent. This is visible, not False.
- For tier B the first clause uses Δ̄ and the second is absent.

Justification of the 1/10:
- The clip level is a modelling choice inside the estimand. It is an epistemic row of the uncertainty budget, not included in the interval.
- NVVUQ.9 and the `uq-budget` rule require every non-sampling row to be at least 10 times smaller than the sampling half-width.
- At |Δ| = hw/10, adding Δ to the interval in quadrature widens it by 0.5%, and a full shift moves a bound by 10% of hw. Below that, the choice of L is immaterial to the verdict.
- The second clause catches the case the ratio rule misses: a deciding bound within |Δ| of a band edge.
- This is DEC-0017 Q6's "3s against one tenth of the half-width", with s made exact as Δ_T.

What is reported:
- The flag sits **next to the verdict and never changes it**. `verdict`, `reason` and `pass` (DEC-0012) are untouched, and the `verdicts` block is unchanged.
- There is no provisional mark. Whether a flag, a sentinel or a collapsed ν cap marks results provisional is the owner's Q6 ruling.
- RESULTS.md gets one more column, "clip", in each verdict row. It shows "—" when n_aff = 0 and C = ∅, "ok (|Δ|/hw = x)", or **"CLIP-SENSITIVE (|Δ|/hw = x; at 20 σ_x: verdict₂)"**.
- `held_fixed_entries` > 0 adds the note "tree, A3 and KM inputs contain N clipped entries; not recomputed".
- One `logging` WARNING line is written per fired flag (PRIME.4: never silent).

### 5. Invariance (tier D), with the hypotheses checked

1. **H1c, the regime targets ln T, and every `characteristic_horizon`** (`oracle.py:322-353`): event ⇔ sqrt(mse + ρ²) > θ.
   - P₂ only raises clipped squares, so an exceedance at L persists at 2L.
   - Conversely, a horizon where P₂ changes anything carries at least one clipped draw, so mse ≥ L²/M there. If L²/M > θ_max² (H-M1), it already exceeded at L.
   - So the first exceedance is identical, for H1c on sq_plp and sq_cp.
   - For the hybrid oracle target `state_horizon_target`, h² ≥ ((1−w*)L − w*|e_C|)² is needed, which fails as w* → 1. ln T of the tree is therefore *not* covered. It is a held-fixed input, counted in `held_fixed_entries`.
2. **H2a(i)**: a state is in the small-error regime iff sqrt(sq) ≤ r_lin = 0.5 at 1, 2 and 4 LT. A clipped draw gives sq ≥ L²/M > r_lin² (H-M2), so that state is excluded at L and at 2L. The median range is unchanged.
3. **H3a and the KM curves** (realized horizons, `oracle.py:356-378`): a clipped entry exceeds θ at both L and 2L if (1−w)L > θ + w·e_max + 4ρ (H-W). For Lorenz-63 (e_max ≈ 4.9) this needs w ≲ 0.49. When it fails, a cancellation w e_C ≈ −(1−w)σL can keep |h| ≤ θ at one of the two levels.
   - Run-time check: the number of clipped test evaluation entries at any horizon (`clip_entries` of the test split). If it is 0, H3a is exactly invariant.
   - Otherwise H3a reports `clip_invariance = "not guaranteed"` and the count. No recomputation.

At every preset, M = 200 (smoke 30): L²/M = 0.5 (smoke 3.3) > θ_max² = 0.25 = r_lin². So H-M1 and H-M2 hold. They are asserted at run time as `L**2 / M > max(max(thresholds)**2, linear_regime_rms**2)` (NVVUQ.14). If they fail, the tier-D verdicts report "outside the invariance hypothesis". Raising M to 400 or more would break them.

**Correction.** In A1.1, condition P-c reads "`a5_2[:, col]` equals `a5_0[:, col]` bitwise, all K rows". It should read: **`a5_2[k, col]` equals `a5_0[k, col]` bitwise for every regime k with at least one calibration member, plus every row (including the empty regimes) if some test draw lies in an empty regime**. This is what `clip_sensitivity.py` checks (`rows = ~empty | empty_used`, at e6d31ed). The sentence "(a)–(d) imply P-c" and the consistency assertion refer to this row set.

**Proof.**
- **Test durations and events.** The H3a verdict reads A5 weights in two places. The first is the test draws' durations and events. Draw i is scored with row k_i of its own regime only, so only the rows of regimes that hold a test draw are read.
- **Kaplan–Meier order.** The second is the order of `horizons_km`. Each entry comes from the calibration members of regime k, using row k. An empty regime has no member, so its entry is NaN whatever its weights. Hence the empty rows are read only if a test draw lies in an empty regime (`empty_used`).
- **Non-empty rows.** A non-empty row is `regime_weight` on the calibration oracle. Under (c), that has no clipped entry, so the row is bitwise unchanged.
- **Empty rows.** An empty row is A2′, the construction-oracle fallback. When `empty_used` holds, (d) leaves the construction oracle without a clipped entry, so A2′ = A2 bitwise.
- **Conclusion.** Therefore (a)–(d) imply the corrected P-c, and the P₂-sufficiency argument of A1.1 is unchanged.
- **Why "all K rows" was wrong.** It would have raised a false defect in T14(ii): an empty regime, a clipped construction oracle, and no test draw in that regime. There (d) does not apply, so A2′ ≠ A2 on a row that H3a never reads.

`weight_shift.A5_max` in the cause string is still the maximum over all rows. It is a report-only descriptor.
